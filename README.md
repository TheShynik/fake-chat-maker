# Fake Chat Maker

Create animated fake chat conversations in WhatsApp, iMessage, Telegram, or Dark style.

## ▶ Live Demo

https://theshynik.github.io/fake-chat-maker/

> If the demo does not open yet, enable **GitHub Pages** in **Settings → Pages → Deploy from a branch → `main` → `/ (root)`**.

## How to Use

1. Open **Fake Chat Maker** in your browser.
2. Go to **Customize**:
   - Choose a chat style: WhatsApp, iMessage, Telegram, or Dark.
   - Change the contact name, avatar, and status.
   - Customize bubble colors, font size, chat size, and background.
3. Go to **Messages**:
   - Click **+ Their message** to add a message from the other person.
   - Click **+ My message** to add your reply.
   - Add **Big Emoji** or **Typing…** if you want.
   - Set the delay between messages.
4. Click **▶ Preview** to play the fake conversation.
5. Click **↺ Reset** to replay it.
6. You can also type directly into the message field and press the send button to simulate sending a message.
7. Go to **Export** when you're happy with the result:
   - Choose landscape, portrait, square, or source size.
   - Choose where the chat appears on screen.
   - Click **Export WebM** to save the animated chat.

## Running Locally

Download or clone the repository and open `index.html` in Chrome or Edge.

For video export, open the app in a normal browser tab rather than inside a preview iframe.
